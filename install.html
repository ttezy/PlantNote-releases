iPhone / iPad

植记要求 iOS / iPadOS 15.0 或更高版本。当前提供无签名 IPA，需要通过 SideStore 等工具签名后安装；下载 IPA 本身不会完成安装。

已经配置好 SideStore？直接添加植记预览源。

Android

多数现代 Android 手机选择 ARM64。旧款 32 位 ARM 设备选择 armeabi-v7a；x86_64 适用于对应架构的设备或模拟器。

  1. 在手机上下载与你的设备架构一致的 APK。
  2. 打开下载文件；如果系统提示，允许当前浏览器或文件管理器安装应用，再继续安装。
  3. 打开「植记」，添加第一盆植物。安装完成后，可关闭刚才的外部安装权限。

Windows

提供 x64 便携版，无需安装向导。

  1. 下载 ZIP，右键选择「全部解压」，放到你方便找到的文件夹。
  2. 打开解压后的文件夹，运行 plantnote.exe。
  3. 请保留旁边的 DLL 和 data 等文件，不要只移动 EXE。

如果系统显示发布者或安全提示，请先核对下载来源和 SHA-256。无法判断提示原因时，先停止运行并保留提示内容。

macOS

要求 macOS 12 或更高版本。本次安装包架构：Apple silicon / Intel。

  1. 下载并打开 DMG 磁盘映像。
  2. 将 plantnote.app 拷贝到「应用程序」，再从那里打开。
  3. 当前预览版尚未发行签名与公证。若系统因开发者无法验证而阻止打开，在确认下载来源和校验值后，可按 Apple 官方说明，在「系统设置 → 隐私与安全性」中允许这一个应用打开。

如果提示包含恶意软件或文件损坏，请先停止安装并重新核对文件，不要关闭系统整体安全保护。

Linux

提供 x64 便携包。解压 TAR.GZ，在含有 plantnote 的文件夹中打开终端：

chmod +x plantnote
./plantnote

保留同目录的 lib、data 等文件。若终端提示缺少共享库，请根据错误信息和你的发行版安装对应运行依赖。

Web 部署

这里提供的是 可自行托管的网页部署包。本官网只负责介绍和下载，不是植记的在线工作区。

  1. 下载并解压 Web ZIP。
  2. 将包含 index.html 的目录部署到 HTTP(S) 静态服务器根路径，保留所有脚本与资源文件。
  3. 通过服务器地址访问。不要直接双击 HTML 使用 file:// 打开；若部署到子路径，需要相应调整 Flutter 的 base href。

数据保存在当前浏览器。清理站点数据、更换浏览器或更换站点地址，可能导致无法继续访问原来的记录。使用稳定的访问地址，并定期导出 CSV。

校验下载是否完整

每个平台都附有 SHA256SUMS.txt。下载与你的安装包同一版本的校验文件，计算安装包的 SHA-256，并与其中对应文件名一行的值比较；两者应完全一致。

Windows · PowerShell

Get-FileHash .\你的安装包.zip -Algorithm SHA256

macOS · 终端

shasum -a 256 你的安装包.dmg

Linux · 终端

sha256sum 你的安装包.tar.gz

把示例文件名替换成实际下载的文件名。校验值不同就不要继续安装，请重新下载。GitHub 自动提供的 Source code 压缩包不是应用安装包。

更新与本机数据

新版安装包会出现在下载区和公开 Releases。iOS 用户可在 SideStore 刷新植记预览源，再选择更新。

更新前，保留原应用并导出记录

当前仍在验证覆盖更新和各平台安装流程。不要为了更新先卸载应用，也不要清除应用或浏览器数据。CSV 不包含植物头像和养护照片，暂时不能作为完整备份。

植记目前没有云同步；同一份数据不会自动出现在其他设备上。你可以在设置里导入、导出 CSV，迁移文字资料与养护记录。
